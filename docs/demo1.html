一条命令，挂在真实构建上

brocade 的沙箱服务由 Rust、Go 和 eBPF C 组成。CodeQuest 把记录器挂进平时的构建命令，三种语言各用自己的编译器取语义，再把服务之间的连接对齐。

$cq index --name cube -- make -C components/cube all
  1. 1
    真实构建cargo · go build · clang -target bpf

    记录 CubeAPI 的每次 rustc 调用、各个 Go 服务的包图，以及 bpf2go 发起的 clang 调用。

  2. 2
    原生语义rust-analyzer · go/types · clang

    按编译时的参数，分别取 Rust HIR、Go 类型检查结果和 C 的 AST。

  3. 3
    关系图含 5 类跨边界连接

    服务内部的调用来自编译器；HTTP 路由、gRPC 方法、配置里的插件 ID、接口实现和 BPF 表名，按规则对齐后连上，并单独标注。
